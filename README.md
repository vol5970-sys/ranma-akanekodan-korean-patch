# 란마 1/2 한국어 패치 v0.8

슈퍼패미컴용 『란마 1/2』의 비공식 한국어 팬 번역 패치입니다. 대사와 전투·메뉴·도구·상점·저장 화면을 한국어로 옮기고 가독성을 다듬고 있습니다.

> **v0.8 시험판**  
> 일본판 원본용 IPS입니다. 전체 플레이 검수는 완료되지 않았으며 아래의 알려진 문제를 확인하고 사용해 주세요.

> 이 저장소는 게임 ROM을 배포하지 않습니다. 패치는 본인이 소유한 정품에서 추출한 **일본판 무헤더 ROM**에만 적용하세요. 영어 팬번역판 ROM은 적용 대상이 아닙니다.

## v0.8에서 진행한 작업

- 추가로 발견된 영어 대사와 표지판을 한국어로 바꿨습니다. 료가 재합류 알림, 란마의 반응 대사, 붉은 고양이단 표지판 등이 포함됩니다.
- 대사 직후 메뉴에 세로 줄이 나타나는 제보를 바탕으로 글꼴 복원 범위를 조정했습니다. 간헐적인 오류가 실제 플레이에서 해결됐는지는 아직 확인하지 못했습니다.
- 일본판 원본에 바로 적용되는 IPS인지와 기존 데이터가 의도치 않게 바뀌지 않았는지 자동 검사 295건을 진행했습니다(285건 통과, 10건 건너뜀). 자동 검사 통과가 전체 플레이 검수 완료를 뜻하지는 않습니다.

**아직 남은 문제:** 엔딩 스태프롤의 글자 깨짐은 수정되지 않았습니다. 일부 대사·화면에 번역 누락이나 표시 오류가 남아 있을 수 있습니다.

## 패치 받기

[GitHub Releases](https://github.com/vol5970-sys/ranma-akanekodan-korean-patch/releases)에서 `ranma_korean_v0.8.ips`를 받으세요. 이 저장소는 ROM이나 BAT 설치 스크립트를 배포하지 않습니다.

파일명만으로 판단하지 말고 아래의 SHA-256도 확인해 주세요.

## 적용 방법

1. 본인이 소유한 정품에서 추출한 **일본판 무헤더 ROM**을 준비하고 원본의 SHA-256을 확인합니다.
2. 일반 IPS 패치 도구로 `ranma_korean_v0.8.ips`를 **원본 ROM의 복사본**에 직접 적용합니다. v0.7이나 v0.7A를 먼저 적용하지 않습니다.
3. IPS 및 적용 후 ROM의 SHA-256, 용량을 확인합니다.
4. 에뮬레이터에서 새 ROM으로 실행합니다.

| 확인 항목 | 값 |
| --- | --- |
| 적용 전 일본판 무헤더 ROM SHA-256 | `98a7d94481ba3caae94693c2d3a28dd54a4388a9d459975999d473becef477b6` |
| `ranma_korean_v0.8.ips` SHA-256 | `cf4f4d3c1e4baa9f46c87e9400a1d4866b9fd3375352f86c4fdcfc70dd2546da` |
| v0.8 적용 후 ROM SHA-256 | `4492684cf2939d555bad52720254d1063edda21e7833e57127b41e6fdb369fee` |
| 적용 후 ROM 크기 | **2,097,152바이트 (2 MiB)** |

해시가 다르면 적용을 멈추고 ROM의 지역판·헤더 유무와 IPS 파일을 다시 확인하세요. **영어 팬번역판을 먼저 적용할 필요가 없습니다.**

## 현재 작업 상태

- 대사와 전투·메뉴·도구·상점·저장 화면의 한국어화 및 가독성 수정을 진행하고 있습니다.
- 일본판 원문을 기준으로 아이템 이름을 다시 대조하고 있습니다.
- 아직 영어 문구나 일본어 그림 글자가 남아 있을 수 있으며, 전체 게임 경로와 모든 에뮬레이터에서 검수가 완료된 것은 아닙니다.
- v0.7A의 온천 안내문·아카네 재합류 알림과 v0.8의 추가 문장·메뉴 수정은 실제 화면 재검수가 필요합니다.

패치 버전을 바꿔 적용할 때는 이전 버전의 **실행 중 저장 상태(save state)**를 이어 쓰지 않는 것을 권장합니다. 게임 내 저장 데이터도 중요한 경우 백업해 두세요.

## 문제 제보

[Issues](https://github.com/vol5970-sys/ranma-akanekodan-korean-patch/issues)에 패치 버전, 에뮬레이터·코어 이름, 발생 장소, 재현 방법과 화면 사진을 남겨 주세요. 엔딩 스태프롤 문제는 엔딩 직전 저장 상태가 있으면 원인 추적에 도움이 됩니다. **ROM 파일은 올리지 마세요.**

## 권리 및 글꼴

이 프로젝트는 비공식 팬 작업이며, 원작과 게임의 권리는 각 권리자에게 있습니다. 한국어 글꼴에는 Galmuri를 사용했습니다. 글꼴 저작권과 라이선스는 배포물에 포함된 Galmuri 라이선스 문서를 확인해 주세요.
