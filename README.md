## 적용 방법

1. 본인이 소유한 정품에서 추출한 **일본판 무헤더 ROM**을 준비합니다.
2. 아래 SHA-256 값과 동일한 ROM인지 확인합니다.
3. IPS Patch Tool로 `ranma_korean_v0.7.ips`를 해당 ROM에 적용합니다.
4. 패치 적용 후 ROM 용량은 **2MB (2,097,152 bytes)**가 됩니다.
5. 기존 버전의 세이브/상태 저장은 사용하지 않는 것을 권장합니다.

| 항목 | SHA-256 |
|---|---|
| 적용 전 일본판 무헤더 ROM | `98a7d94481ba3caae94693c2d3a28dd54a4388a9d459975999d473becef477b6` |
| v0.7 패치 적용 후 ROM | `f05af39550c4b7ef55decc72e10829b885f1a7e76cf49442f78b65182254c206` |
| `ranma_korean_v0.7.ips` | `08e722f208bfc6c42587d1ed07771902c48b5cc98b577db6ee62cb6c1d164328` |

### 주의

- 이 패치는 **일본판 원본 무헤더 ROM 전용**입니다.
- 별도의 영문 팬패치를 먼저 적용할 필요가 없습니다.
- 헤더가 붙은 ROM이나 다른 버전의 ROM에는 정상 적용되지 않을 수 있습니다.
- ROM 파일 자체는 배포하지 않습니다.
