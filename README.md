# 란마 1/2 한국어 패치 v0.7A

슈퍼패미컴용 『란마 1/2』의 비공식 한국어 팬 번역 패치입니다. 대사와 전투, 메뉴, 도구, 상점 등 게임 화면을 한국어로 옮기는 작업을 진행하고 있습니다. **아직 전체 플레이 검수가 끝나지 않은 시험판**입니다.

> 이 저장소는 게임 ROM을 배포하지 않습니다. 패치는 본인이 소유한 정품에서 추출한 **일본판 무헤더 ROM**에만 적용하세요. 영어 팬번역판 ROM은 적용 대상이 아닙니다.

## 패치 받기

[GitHub Releases](https://github.com/vol5970-sys/ranma-akanekodan-korean-patch/releases)에서 일본판 원본용 IPS를 받으세요. 파일명만 믿지 말고, 아래 SHA-256 값도 확인해 주세요. BAT 파일이나 별도 실행 프로그램은 필요하지 않습니다.

이번 업로드용 버전은 **v0.7A 검수판**입니다. 기존 v0.7 이후의 아이템 이름 수정과 제보받은 대사 수정이 누적되어 있습니다. 전체 플레이 검수는 아직 진행 중입니다.

## 적용 방법

1. 본인이 소유한 정품에서 추출한 **일본판 무헤더 ROM**을 준비합니다.
2. 원본 ROM의 SHA-256이 아래 값과 일치하는지 확인합니다.
3. IPS 패치 도구로 일본판 원본용 `ranma_korean_v0.7A.ips`를 ROM에 적용합니다. 원본을 보관하고, 복사본에 적용하는 것을 권장합니다. **v0.7을 먼저 적용하지 마세요.**
4. 적용 후 ROM 크기와 SHA-256을 확인한 뒤 에뮬레이터에서 새로 엽니다.

| 확인 항목 | 값 |
| --- | --- |
| 적용 전 일본판 무헤더 ROM SHA-256 | `98a7d94481ba3caae94693c2d3a28dd54a4388a9d459975999d473becef477b6` |
| 일본판 원본용 v0.7A IPS SHA-256 | `a42ab00b14f524c0466bd8fb1c5f6eda9c9acac607981bdcf643f18b8da2e294` |
| v0.7A 적용 후 ROM SHA-256 | `0def5312513cade7a44ba65164fe259c50bc33934db64b93a79a8c0b5e2d379e` |
| 적용 후 ROM 크기 | **2,097,152바이트 (2 MiB)** |

해시가 다르면 적용을 멈추고 ROM의 지역판·헤더 유무와 IPS 파일을 다시 확인하세요. **영어 팬번역판을 먼저 적용할 필요가 없습니다.**

## 현재 작업 상태

- 대사와 전투·메뉴·도구·상점·저장 화면의 한국어화 및 가독성 수정을 진행했습니다.
- 일본판 원문을 기준으로 아이템 이름을 다시 대조하고 있습니다.
- 아직 영어 문구나 일본어 그림 글자가 남아 있을 수 있으며, 전체 게임 경로와 모든 에뮬레이터에서 검수가 완료된 것은 아닙니다.
- v0.7A에는 온천 안내문, 란마의 거리 대사, 아카네 재합류 알림 수정이 포함됩니다. 이 세 장면의 실제 화면 재검수는 아직 필요합니다.

패치 버전을 바꿔 적용할 때는 이전 버전의 **실행 중 저장 상태(save state)**를 이어 쓰지 않는 것을 권장합니다. 게임 내 저장 데이터도 중요한 경우 백업해 두세요.

## 문제 제보

[Issues](https://github.com/vol5970-sys/ranma-akanekodan-korean-patch/issues)에 패치 버전, 사용한 에뮬레이터, 문제가 발생한 장소와 재현 방법, 가능하면 화면 사진을 남겨 주세요. ROM 파일은 올리지 마세요.

## 권리 및 글꼴

이 프로젝트는 비공식 팬 작업이며, 원작과 게임의 권리는 각 권리자에게 있습니다. 한국어 글꼴에는 Galmuri를 사용했습니다. 글꼴 저작권과 라이선스는 배포물에 포함된 Galmuri 라이선스 문서를 확인해 주세요.
