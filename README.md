# 란마 1/2 한국어 패치 v0.7

이 배포본에는 **패치 파일만** 들어 있습니다. 게임 ROM은 포함하지 않습니다.

프로젝트 주소: <https://vol5970-sys.github.io/ranma-akanekodan-korean-patch/>

IPS 직접 다운로드: <https://github.com/vol5970-sys/ranma-akanekodan-korean-patch/releases/download/v0.7/ranma_korean_v0.7.ips>

자료: [기술 분석](TECHNICAL_NOTES.md) · [검수 현황](QA_STATUS.md)

BAT 파일은 필요하지 않습니다. IPS 패치 도구로 직접 적용하세요.

## 적용 방법

1. 본인이 소유한 정확한 **무헤더 영문판** ROM을 준비합니다.
2. ROM의 SHA-256이 아래 기준값과 같은지 확인합니다.
3. IPS 패치 도구로 `ranma_korean_v0.7.ips`를 해당 ROM에 적용합니다.
4. 에뮬레이터에서 패치된 ROM을 새로 열고, 게임 안에서 만든 저장을 불러옵니다. 이전 버전의 실행 중 저장 상태(save state)는 사용하지 않는 편이 안전합니다.

| 항목 | SHA-256 |
|---|---|
| 적용 전 무헤더 영문 ROM | `ea5d333b6c29ade4ae5a7819e6a2cf8b5179bf24aeed2d5346995eb7360e6289` |
| v0.7 패치 적용 후 ROM | `f05af39550c4b7ef55decc72e10829b885f1a7e76cf49442f78b65182254c206` |
| `ranma_korean_v0.7.ips` | `6d6ab6e3f99f4fbd9a6da2eb94d923ca2080dce15cc0340431de355787aa9b41` |

## 주요 내용

- 대사와 전투·도구·상점·시스템 화면의 한국어 패치를 누적했습니다.
- 전투 후 문구, 아이템 이름 일부, 체력 표시 정렬과 몸 장비의 `옷` 분류를 수정했습니다.
- v0.7에서 전투 상태창의 무스·료가·겐마 이름 그림 위치를 바로잡고, 샴푸·무스 그림의 겹침을 수정했습니다.

## 현재 제한

- 이 패치는 진행 중인 시험판입니다. 전체 게임 경로의 플레이 검수는 완료되지 않았습니다.
- 특히 v0.7의 후기 동료 이름은 원본 그림 경계와 별도 에뮬레이터의 글자 로딩을 확인했지만, 해당 동료가 실제 참여한 전투 화면은 아직 최종 검수 전입니다.
- 참고 이미지 수준의 큰 상태창·얼굴 그림 배치는 아직 완성되지 않았습니다.

한글 글꼴에는 Galmuri를 사용했습니다. 라이선스는 `Galmuri-OFL.txt`를 참조하세요.
