HOW TO APPLY

적용 방법

  1. 본인이 소유한 무헤더 영문판 ROM을 준비합니다. SHA-256은 ea5d333b6c29ade4ae5a7819e6a2cf8b5179bf24aeed2d5346995eb7360e6289여야 합니다.
  2. IPS 파일을 내려받아 IPS 패치 도구로 적용합니다.
  3. 패치 후 ROM의 SHA-256 f05af39550c4b7ef55decc72e10829b885f1a7e76cf49442f78b65182254c206를 확인한 뒤 에뮬레이터에서 새로 엽니다.

이전 버전의 실행 중 저장 상태(save state)보다는 게임 안에서 만든 저장을 불러오세요. 후기 동료 전투 화면과 전체 진행 구간은 아직 최종 검수 전입니다.
